Help & Setup
CORS Configuration (required for browser access)
In AWS Console → S3 → Your Bucket → Permissions → CORS: 
[{
  "AllowedHeaders": ["*"],
  "AllowedMethods": ["GET","PUT","POST","DELETE","HEAD"],
  "AllowedOrigins": ["*"],
  "ExposeHeaders": ["ETag"]
}]

Minimum IAM Permissions
s3:ListBucket, s3:GetObject, s3:PutObject, s3:DeleteObject

S3-Compatible Services
Enter the endpoint URL for MinIO, Cloudflare R2, Wasabi, DigitalOcean Spaces, etc. Path-style requests are used automatically.
